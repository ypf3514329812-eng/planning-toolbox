# Planning Toolbox Agent Guidance & Workspace Rules

Welcome to **Planning Toolbox (城乡规划 CAD–GIS 自动化辅助工具箱)**!

## Core Principles
1. **Target Audience**: Urban planning students with no programming background.
2. **User Experience**: Command/config-driven workflow. Never ask users to modify source code.
3. **Core Philosophy**: Humans make planning judgments; code handles calculations and repetitive work.
4. **Git Version Control**: Clean branch management (`main`, `feature/*`, `fix/*`). Stable tags for milestone releases.
