# AI Escalation Rule

- Antigravity handles 70%-85% of tasks (scaffolding, standard code, tests, docs, config, bug fixes, refactoring).
- Escalate to Codex ONLY when criteria C1-C7 are met (persistent bugs after 2 attempts, complex topology proofing, CRS transformations, deep AutoCAD/ArcGIS API bugs, core refactors).
- When escalating, automatically generate `CODEX_ESCALATION.md` following the mandatory template.
