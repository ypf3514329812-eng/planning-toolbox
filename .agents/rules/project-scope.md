# Project Scope Rule

## Bound Boundaries (Phases 0–4)
- Phase 0: Engineering Infrastructure
- Phase 1: CAD Automation (Parcel Calculator, Layer Initialization, Labeling)
- Phase 2: GIS ↔ CAD Data Bridge (GeoPackage/GeoJSON ↔ DXF, CRS conversion)
- Phase 3: Planning Indicators (FAR, Building Density, Green Ratio, Land Use Area)
- Phase 4: Rules & Topology Validators (Open polyline, self-intersection, setback compliance)

## Out of Scope (Do NOT implement unless explicitly requested)
- Autonomous AI Urban Design
- Automatic 3D Architectural Generation
- Large Web SaaS / Cloud Platforms
- Custom CAD / GIS CAD engines from scratch
