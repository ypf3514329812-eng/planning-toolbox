Planning Toolbox SketchUp 模型交接插件

安装：
1. 在 SketchUp 中打开“扩展程序管理器”。
2. 点击“安装扩展程序”，选择 PlanningToolbox_SketchUp_Importer.rbz。
3. 在“扩展程序”菜单中选择“导入 Planning Toolbox 模型交接...”。
4. 选择 Planning Toolbox 导出的 *.ptsu.json 文件。

说明：
- 插件只在本机读取轻量 JSON，不联网、不需要 API。
- 生成对象按 PT_* 标签分层，并保留对象 ID、来源图层和 DXF handle。
- INSERT 与嵌套 INSERT 会保留为分组；3DFACE/SOLID/TRACE 会生成可编辑面。
- CAD 文字可在导出时选择为 SketchUp 标签，默认关闭以避免模型杂乱。
- 三维建筑高度只使用导出时明确填写的楼层数和层高。
- “课程作业”和“汇报模型”会程序化生成楼层线、屋顶/女儿墙和共享窗组件；“快速体量”保持最轻。
- 课程/汇报模式会生成建筑基座、入口与雨棚；入口位置会避让首层窗。
- 汇报模式可为住宅生成有界数量的共享阳台，为平屋顶增加轻量设备箱，并按建筑用途使用低饱和材质。
- 课程/汇报模式会把 PT_TREE、TREE_SYMBOL 等树木块转换为共享的低多边形三维树组件，重复树木不会各自复制整套几何。
- 闭合道路、绿地、水体和停车轮廓会获得克制的高差与薄层，减少重叠闪烁并增强场地可读性。
- 规则四边形道路可生成有界的中心虚线；道路边缘与停车面会生成路缘或标线。
- 建筑、场地和植被细节由 Planning Toolbox 的轻量规则知识库驱动；交接文件记录规则版本和来源数量，不包含网上图片、SKP 或模型权重。
- 同一项目重复导入时只替换发生变化的顶层对象，未变化对象会保留。
- 手工调整重点建筑前，可在“扩展程序”菜单锁定选中对象；后续增量导入不会覆盖锁定对象。
- 结果属于辅助模型，复杂曲线、块、文字、材质和专业规范仍需人工复核。
